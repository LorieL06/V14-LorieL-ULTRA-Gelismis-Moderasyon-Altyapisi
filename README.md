# V14 LorieL Moderasyon Altyapısı

Bu proje, Discord.js v14 ile geliştirilmiş, özelleştirilebilir ve geliştirilebilir bir **moderasyon botu altyapısıdır**. Proje, temel moderasyon komutlarını, güvenlik kontrollerini ve sunucu yönetim özelliklerini barındırır.

## 🚀 Özellikler

- Discord.js v14 ile tam uyumlu yapı
- Gelişmiş moderasyon komutları
- Hatalı kullanım engelleme ve komut loglama
- Kapsamlı kullanıcı/sunucu güvenlik sistemleri
- Kolayca özelleştirilebilir komut sistemi
- Türkçe destekli altyapı

## 🛠️ Kullanım

> Node.js v16.9+ veya v18+ önerilir.


git clone https://github.com/kullaniciadiniz/V14-LorieL-Moderasyon-Altyapi.git
cd V14-LorieL-Moderasyon-Altyapi
npm install

Ardından config.json dosyasını düzenleyerek bot token'ınızı ve diğer ayarları girin

Botu başlatmak için:

node .


## 📁 Dosya Yapısı

- commands/ – Komutların bulunduğu klasör

- events/ – Bot olayları (ready, messageCreate vs.)

- config.json – Bot ayarları

- index.js – Ana bot başlatıcısı
